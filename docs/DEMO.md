# Демонстрация реальной интеграции

Автоматические тесты используют подмену HTTP-транспорта только внутри тестового проекта. В приложении нет деморежима, локальной коллекции лидов или имитации успеха.

## Подготовка

1. На собственном тестовом портале включите лиды и создайте входящий вебхук с `crm` от пользователя с правами создания и чтения.
2. Проверьте `profile.json` в локальном REST-клиенте, не записывая секретный адрес на видео и скриншоты.
3. Выполните `scripts/Start-Local.ps1`, введите URL скрытым вводом.
4. Откройте `http://localhost:5180/` и `/swagger/index.html`.

## Успешный сценарий

1. Введите синтетические имя, телефон и комментарий. Например: «Тестовый клиент», «+7 (000) 000-00-00», «Учебная проверка интеграции».
2. Отправьте форму один раз. Проверьте блокировку кнопки и сообщение отправки.
3. После успеха сохраните показанный ID. Он должен быть получен из настоящего ответа CRM.
4. На портале найдите лид с этим ID; сравните `title`, имя, нормализованный телефон и комментарий.
5. В Swagger вызовите GET `/api/leads?start=0`; найдите лид, при необходимости переходите по `nextStart`.
6. Сделайте скриншот карточки **только тестового лида**, не включая токен, реальных клиентов и посторонние данные портала. Сохраните как `docs/screenshots/crm-lead.png` и добавьте его в README.

## Ошибочные сценарии

- Пустое имя и телефон с буквами: форма показывает ошибки; Swagger / API возвращает 400 с полями.
- Шестая попытка POST в течение минуты с одного IP: 429 и `Retry-After`.
- Для проверки неверного вебхука используйте только отдельный синтетический неправильный токен на своём тестовом портале, запустив процесс с временной конфигурацией; не меняйте настоящий вебхук и его права. Приложение должно вернуть безопасную ошибку без URL и исходного ответа CRM.
- Нет доступной CRM / тайм-аут: 503/504, данные формы сохраняются. Не повторяйте отправку, пока не уточнили, появился ли лид.
- Перезапустите с `--no-launch-profile` и `ASPNETCORE_ENVIRONMENT=Production`: GET `/api/leads` возвращает 405, Swagger — 404; `/health` остаётся доступным.
